# Data

This project uses a custom dataset (`student_data_2000_3_6_9.csv`) created for this analysis.

The dataset is based on an adapted version of the OECD PISA microdata (2000, 2003, 2006, and 2009) from the Learning Tower project:

https://github.com/kevinwang09/learningtower

Additional preprocessing and modifications were performed for this project.

The dataset is not included in this repository due to file size limitations.
